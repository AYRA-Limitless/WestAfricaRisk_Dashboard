# WBG Risk Dashboard

Interactive dashboard for macro-financial analysis and country risk scoring across West African (ECOWAS) economies, built with Python and Streamlit.

## Purpose
This project was built to support my application to the World Bank Group Pioneers Program.

## Tech Stack
- Python, Pandas, Scikit-learn
- Streamlit
- World Bank Open Data API
